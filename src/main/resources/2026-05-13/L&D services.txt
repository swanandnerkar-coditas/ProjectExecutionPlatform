Flow : 
1. At first / start of application first page User will see form of LOGIN with fields username and password, after filling those fields click on login button
	if the credentials are correct then your're successfully logged in and redirected to dashboard based on user ROLE
	if not then message shown : "Incorrect Credential" and stay on same page
2. Role wise Dashboard :
	ADMIN :
		ADMIN dashboard opens and has navigation bar on left side, with different buttons on it
		Button "View Profile" : clicking on it redirected to user profile page
			which has user(ADMIN) information [ username, role, joining date, experience ]
		Button "Create Training Course" : click on button which will redirected to create training course page
			It has fields Course name and duration ( time provided to complete it )
			button "create" -> clicking on it'll create course
		Button "Add employee" : click on button which will redirected to register employee page
			where you've form to fill & enter user details to create employee
			fields : username, password, role, experience ( setting password DOB initially then employee can change )
			button "add" -> clicking on it new employee will be registered
		Button "Employee data" : click on button which will redirected to employee data page
			it has 2 drop down list ( based on there value you're applying filter to get result )
				1. Employee, Status : ON_BENCH, ON_PROJECT
				2. Employee, Course : ENROLLED, NOT_ENROLLED
			button "search" -> clicking on it, based on provided filter will give result : list of employee will be shown on page
	
	EMPLOYEE :
		EMPLOYEE dashboard opens and has navigation bar on left side, with different buttons 
		Button "View Profile" : clicking on it redirected to user profile
			which has user(EMPLOYEE) information [ username, role, joining date, experience ]
			at bottom has button "Change password" clicking on it open page where form has 2 fields : oldpassword & newpassword , 1 button "update" -> clicking on it
				if oldpassword is right ( current password is equal to provided old password) then update password of Employee with update password field
				if not then show message : "Incorrect Old password" on same page
		Button "Courses" : clicking on it redirected to courses page
			where all the courses are listed with button "enroll" on side, by clicking on it Employee gets enrolled in course staying on same page
			only list those courses which are not enrolled by Employee already
		Button "My/Enrolled Courses" : clicking on it redirected to enrolled course page
			where all courses are listed which are enrolled by Employee with button "Visit Course" on side
			clicking on "Visit Course" -> redirected to course page
				1. should able see percentage of completion
				2. list of YouTube videos or any links with check box ( arrange 2 columns : 1 for resources another column of check boxes to mark as complete ), click on it when complete that resource.
				3. at last Assignment section with "add" button 
					-> "add" button -> clicking on it assignment will submitted
						if added then Course status is CERTIFIED
					if not then just COMPLETED ( 100% completed but not certified yet till assignment is submit )
		Button "Certificates" : clicking on it redirected to certificates page
			where all certificates will be listed : where Employee Course Status is CERTIFIED ( course 100% complete & assignment is CLEARED )
